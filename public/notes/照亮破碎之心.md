**核心命题**：情绪的来源可以被光照亮，痛苦本身却只能被故事传达——技术的一半叫「照亮」，文学的一半叫「投射」。

## 02 一句话总览

一个每天在精神科一线接诊、又亲手发明了照进大脑之光的人，写下六个病人的故事：失去妻子后再也哭不出来的年轻人、在想象里越写越远的躁狂者、要回家造「法拉第笼」的姑娘、在生命尽头露出婴儿抓握的老人。每章两条线合龙：病例与文学引文把痛苦讲成故事，科学综述把情绪还原成回路。Projections，既是投进大脑的光，也是投给世界的内心。

## 03 核心框架：照亮 vs 投射

英文书名 Projections 是刻意保留的双关：光学上，光被投射（projected）进大脑；心理上，内在状态被投射（projected）到行为与世界。全书六章每章同时运行这两个动作。

| 照亮（把光投进去） | 投射（把里面投出来） |
|---|---|
| 把光敏蛋白装进特定神经元，用光开关 | 把内在状态写成故事，投给另一个心智 |
| 所见：回路——可测、可调、可重复 | 所见：经验——白墙、法拉第笼、抓握的手 |
| 能回答：情绪的物理来源在哪里 | 能回答：痛苦对这个人意味着什么 |
| 语言：数据、模型、环路图 | 语言：病例、引文、叙事 |
| 边界：能解释痛苦，不抵达痛苦 | 边界：能被理解，无法被验证 |

**推理引擎（六步）**：

1. **症状是投影**——躁狂的亢奋、悲伤的沉重、意识的碎裂，都是内在经验投在行为上的形状。
2. **投影过去只能被旁观**——诊断手册描述行为，看不见回路：症状被归类，经验仍是黑箱。
3. **把光投进去**——光遗传学让特定回路开与关，投影第一次有了可检验的物理来源。
4. **但回路有硬边界**——能解释「悲伤从哪里来」，不抵达「白墙里的人怎么办」；一个不再流泪的年轻人，任何一束光照不出他的未来。
5. **把里面投出来**——每章配另一个动作：一个具体的人、一段故事、一页文学引文，把回路翻译回经验。
6. **两半合起来才是书名**——照亮是技术动作，投射是文学动作；医生同时做这两件事，痛苦才同时被看见、被听见。

**落点**：光遗传学解决「看得见」，叙事解决「听得懂」；诊断把人归入类别，讲述把人还给故事。

> **边界卡**：① 病例经过文学加工（作者自述语言为唤起疾病状态而调整），是文学性非虚构而非病历，细节以原书为准；② 光遗传学不是「光线疗法」，截至本书写作仍是研究工具；③ 六种疾病只是六扇窗，诊断的格子是切的，人是连续的谱。

## 04 关键概念卡片

| 概念 | 要点 |
|---|---|
| 投射（双关） | 光学动作与心理动作共用一个动词：光投进大脑，内心投向世界；这是全书的结构本身 |
| 白墙 | 第一章：未来如同一堵看不见的、无法突破的、无形无相的白墙——抑郁不是悲伤太多，是时间的可见性失效 |
| 眼泪的混合 | 「当我们同时感受到希望与脆弱时，我们才会流泪」——眼泪是两种相反信号的混合，情绪不是单一回路的输出 |
| 大脑的神不知鬼不觉 | 第二章躁狂：想象的故事细节自动生长，「大脑已经神不知鬼不觉地开始重塑」——意义生产失去刹车 |
| 法拉第笼 | 第四章温妮：「我会回家去，完成我的法拉第笼」——妄想隔绝无法承受的信号；读懂妄想的捷径是问它挡住了什么 |
| 与疾病的伙伴关系 | 第五章：病人和疾病之间存在伙伴关系——疾病给奖励也收租金，拆散的是一段长期合租的关系 |
| 抓握反射 | 第六章：临终老人做出婴儿般的抓握——退行不是消失，是露出底座 |
| 共病时代 | 个例拼出的时代诊断：每个人都或多或少滑向抑郁；六种疾病不是六种人，是六个方向上的普通人 |

## 05 全书脉络：六扇窗，一条下沉线

| 章 | 核心病例与意象 | 在谱系上的位置 |
|---|---|---|
| 第一章 抑郁症 | 失去妻子后再也哭不出来的年轻人；白墙；红绿灯里化开的泪 | 情绪的下限：未来的消失 |
| 第二章 躁狂症 | 把想象中的父女故事讲成真实；大脑「神不知鬼不觉地重塑」 | 意义生产失去刹车 |
| 第三章 边缘型人格障碍 | 十九岁的少年；痛苦与关系像过山车 | 痛苦优先于快乐的行为逻辑 |
| 第四章 精神分裂症 | 要回家完成「法拉第笼」的姑娘 | 自我与现实边界的破裂 |
| 第五章 厌食症 | 十八岁的学生；与疾病「合租」 | 把身体变成战场 |
| 第六章 痴呆症 | 不再说话的老人说出完整的句子；婴儿般的抓握 | 自我逐层褪尽，露出底座 |
| 后记 | 回到写作的动机 | 把六扇窗合成一扇门 |

**递进逻辑**：前三章是情绪的「过量与匮乏」（太沉的悲伤、太满的意义、太陡的起伏），后三章是自我的「边界与消退」（现实的边界、身体的边界、自我的底座）。排序本身就是论点：精神疾病不是并列的清单，是一条从情绪走向自我的连续下沉线。

## 07 对工作与决策的行动启发

1. **把「异常」翻译成「放大」**：遇到难以理解的行为，先问它放大了什么——法拉第笼在挡什么信号，白墙在遮什么未来。
2. **讲述本身就是干预**：心理的痛苦没有化验单，能说出口、被听见的故事已经是处理的一部分；先听完故事，再谈解决方案。
3. **两种工具都要有**：数据看得见回路，故事听得懂经验；只用一种，都会漏掉一半真相。
4. **给自己留一个白墙指数**：睡眠、食欲、对具体未来的想象能力，都是可自查的信号；当未来开始像白墙，就是找人讲述的时候。
5. **警惕把技术当救赎**：照亮是工具不是答案；对任何具体的人，先讲后照。

## 08 适合谁读

- 陪伴过精神疾病患者的人：这本书把病与人的关系讲得比多数科普诚实；
- 医务、心理、社工从业者：文学性病例叙事的范本；
- 对脑科学好奇、又怕教科书枯燥的普通读者：引文、病例、科学综述三层结构，可当非虚构文学读；
- 写作者：作者自述为每种疾病调整了语言质感，是研究「语言如何唤起状态」的活教材；
- 不适合：正处在急性发作期或刚经历重大丧失的人（病例细节可能触发）；想找诊断标准或治疗方案的人。
