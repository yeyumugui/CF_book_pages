# 非暴力沟通

> **一句话**：非暴力沟通不是一种说话方式，是一种**归因方式**——你说的每句话都在回答"这件事为什么发生"，答案指向对方就是暴力，指向需要就是联结。

**作者背景（与本书的方法直接相关）**

卢森堡在底特律内城长大，童年每天目睹不同形式的暴力。为了弄清"暴力从哪里来、能不能减少"，他去读心理学，1961 年在威斯康星大学拿到临床心理学博士学位。1960 年代，他第一次把这套方法用在联邦政府资助的公立学校废除种族隔离项目里做调解；1984 年创立非暴力沟通中心（CNVC）；此后在 60 多个国家做过培训，包括卢旺达、中东、北爱尔兰这些正在冲突中的地方。2006 年获"和平之桥"非暴力奖。

这个出身很关键：**他不是从"怎么把话说得好听"出发的，是从"人为什么会伤害人"出发的。** 所以这本书的底层不是话术，是归因。

## 02 一句话总览

**人不是被事情激怒的，是被自己对事情的解释激怒的；非暴力沟通做的全部工作，就是把那句解释里的主语，从"你"改回"我"。**

四要素（观察—感受—需要—请求）经常被当成四个说话步骤，其实它们是**同一句话的四个零件**。缺任何一个，这句话就会退回指责：

> "你总是把袜子乱扔，我很生气，你能不能有点责任心？"
> ——这是三句评判加一句命令。

> "我看到咖啡桌下有两只袜子、电视机旁有三只；我不太高兴，因为我看重整洁；你愿意把袜子放进洗衣机吗？"
> ——这是书里那位母亲的原话结构：四个零件齐全，一句话没有一个字在判断对方是什么人。

## 03 核心框架：疏离生命的语言 vs 联结生命的语言

| | **疏离生命的语言**（异化的沟通） | **联结生命的语言**（非暴力沟通） |
|---|---|---|
| 注意力落点 | 对方**是什么人**（对/错、好/坏、正常/不正常） | 我**需要什么**（以及对方需要什么） |
| 典型句式 | "你太自私了""你从来不……""你让我很失望" | "我看到……我感到……因为我需要……你愿意……吗" |
| 归因方向 | 原因在对方的行为、人品、态度 | 原因在我的需要是否被满足；对方的行为只是**刺激** |
| 代价 | 对方听到的是批评，第一反应是防御或反击 | 对方听到的是一个可回应的具体请求 |
| 结果 | 赢了这一句，输掉这段关系 | 不一定得到同意，但保住了继续谈的可能 |

**四种"疏离生命的语言"（第二章）**

1. **道德评判**——用"自私/懒惰/不负责"这类词给人定性。注意：价值判断（我看重诚实）不是道德评判（你不诚实就是坏人）。
2. **进行比较**——"别人家的孩子""隔壁组的进度"。书里引丹·格林伯格《让自己过上悲惨生活》：真想活得惨，就去跟人比。
3. **回避责任**——"不得不""你让我""领导要求的""大家都这样"。这些短语的共同作用，是把"我选的"说成"我没得选"。
4. **强人所难**——要求里暗含威胁：不配合就受罚。这是强者最常用的手段。

**这套框架真正的推理引擎**

> **感受的根源在自身，不在别人的行为。**

这不是一句安慰，是一个可以检验的因果判断。同一件事（对方迟到一个小时），在不同需要状态下会产生完全不同的感受：如果你急需他到场签字，你感到焦虑；如果你只是想见他，你感到失落；如果你本来就想独处，你甚至感到轻松。

**行为是常量，感受是变量，所以变量不在行为里，在需要里。**

"你让我生气"这句话在语法上完成了一次责任转移：它把因果的主语交给了对方。而一旦原因在对方，唯一的解法就是**对方改变**——这就是所有僵局的结构。反过来，一旦原因回到自己的需要，解法立刻多出很多条：说清楚需要、换一种满足方式、降低期待、放弃这段关系。

**所以四要素的作用不是让你说话客气，是让你重新拿回因果的主语。** 这也是为什么这本书最难的部分不在第一章，而在第九章"爱自己"。

## 04 关键概念卡片

**① 异化的沟通方式（第二章）**
道德评判、进行比较、回避责任、强人所难。四者的共同点：都在**评价人**，而不在**说明事**。它们能快速满足"我要他认错"的愿望，代价是对方再也听不见你真正想要什么。

**② 四要素（第一章）**
观察（发生了什么，可被录像）→ 感受（我的身体和情绪状态）→ 需要（哪个需要被满足/未被满足）→ 请求（你愿意做一件具体的事吗）。四步齐全才叫完整表达；少一步，听的人就会自动补上最坏的那个解释。

**③ 观察 ≠ 评论（第三章）**
"你最近很冷淡"是评论；"这三天我发了五条消息，收到一条回复"是观察。检验标准是**摄影机测试**：如果现场有台摄像机，画面和这句话一致吗？卢森堡引克里希那穆提的话——"不带评论的观察，是人类智力的最高形式。"他还补了一句自嘲：第一次听到这话时心想"这是什么废话"，然后立刻意识到，自己刚刚已经做了一个评论。

**④ 感受 ≠ 想法（第四章）**
"我觉得你不重视我"不是感受，是**对他人态度的判断**。"我感到孤单""我感到慌"才是感受。分辨方法：感受后面能接"因为"，想法后面通常接"你"。

**⑤ 感受的根源（第五章）**
听到不中听的话，人有四种选择：责备自己、指责他人、体会自己的感受和需要、体会他人的感受和需要。前两种最省力，也最没用——它们都在找一个"责任人"，而不在找一个"解法"。

**⑥ 请求 ≠ 要求（第六章）**
判断标准只有一条：**这个请求能不能被拒绝。** 能被拒绝的才是请求；不能被拒绝的，本质是要求，要求背后一定跟着惩罚（冷战、贬低、撤资源）。所以四要素里最难的是最后一步——它要求你真的接受"不"，并且不因此惩罚对方。请求还要具体、正向、可执行："你愿意多关心我一点"不是请求，"你愿意每周三晚上留一小时不拿手机吗"才是。

**⑦ 倾听 = 翻译（第七、八章）**
倾听不是等对方说完轮到我，是在对方的话里找**他哪个需要没被满足**。书里那个著名的例子：在巴勒斯坦一座清真寺，听众认出他是美国人，有人喊"杀手"。他没有辩解，只是一句句问："你生气，是因为你希望我的政府改变它使用资源的方式吗？""所以你非常生气，是因为你们需要改善生活条件，并且希望能掌握自己的政治命运，对吗？"二十多分钟后，那个人邀请他去家里吃斋月晚餐。
注意他做的事：**不回应急慢的字面，只回应字面背后的需要。** 另外一条实操细节——在一个生气的人面前，永远不要用"不过""可是""但是"。

**⑧ 愤怒四步（第十章）**
愤怒不是要被压下去的东西，它是一封还没翻译的信。四步：停下来，呼吸 → 找出心里那句指责（"他怎么能这样"）→ 连接指责背后的需要 → 把需要和感受说出来。卢森堡不主张"别生气"，他主张"生气时你说的那句话还没翻译完"。

## 05 全书脉络

**四段结构（13 章）**

| 段 | 章 | 内容 | 解决的问题 |
|---|---|---|---|
| 一 · 表达自己 | 1—6 | 让爱融入生活 / 是什么蒙蔽了爱 / 区分观察和评论 / 体会和表达感受 / 感受的根源 / 请求帮助 | 我怎么把话说清楚，而不伤人 |
| 二 · 倾听他人 | 7—8 | 用全身心倾听 / 倾听的力量 | 我怎么听懂对方真正要什么 |
| 三 · 对自己 | 9—11 | 爱自己 / 充分表达愤怒 / 运用强制力避免伤害 | 我怎么不把自己也当成敌人 |
| 四 · 收束 | 12—13 | 重获生活的热情 / 表达感激 | 这套方法最后指向什么 |

**关键节点**

- **1960s 初**：第一次应用，在联邦政府资助的公立学校废除种族隔离项目中做调解与沟通培训。
- **1984**：创立非暴力沟通中心（CNVC）。
- **2003**：联合国教科文组织将其列为全球非暴力解决冲突的最佳实践之一。
- **2006**：获"和平之桥"非暴力奖。
- **2015-02-07**：卢森堡去世。全球销量逾 700 万册，40 多种语言。

**两条容易被跳过的暗线**

1. **第九章"爱自己"才是全书的地基。** 如果这套语言只用来对别人说，它就变成了更精致的说服术。卢森堡的要求是：把"不得不"全部改写成"我选择做，因为我需要……"。填得出需要，这件事是你选的；填不出，这件事本身就该重新决定。**对自己用不了这套语言的人，对别人用的一定是话术。**
2. **第十一章"运用强制力"是他最反直觉的一章。** 他不反对强制力，他区分了两种：**惩罚性强制力**（目的是让人后悔、吃苦、长记性）与**保护性强制力**（目的只是阻止正在发生的伤害）。后者只针对行为、不针对人，不追究过去，也不要求对方认错。这一章其实在说：**有些场景不该继续"沟通"，该做的是先止住伤害。**

## 07 对工作与决策的行动启发

1. **评审会先给事实，再给判断。** 把"这个方案不行"换成"这版没覆盖 XX 和 XX 两个场景"。前者要求对方认输，后者邀请对方补充。
2. **对上沟通删掉"不得不"。** "老板让我做的"→"我选择做，因为我需要保住这个季度的交付"。如果填不出需要，这件事值得重新谈一次，而不是硬扛。
3. **提要求时明说"你可以拒绝"。** 不说这句，你发出去的是命令，收到的只会是服从或抵抗——而抵抗通常以"阳奉阴违"的形式出现，成本比拒绝高得多。
4. **冲突升级时先翻译，再回应。** 对方说的每句指责，先在心里翻成"他哪个需要没被满足"，然后回应需要，不回应字面。回应字面只会加固对立。
5. **写事故报告、复盘、绩效反馈时用摄影机测试。** 每句话问一遍：如果有录像，画面和这句话一致吗？"经常延迟"过不了测试，"本季度 8 个需求平均延迟 11 天"能过。
6. **愤怒的时候先别开口。** 按四步走一遍：停 → 我在指责谁 → 我哪个需要被踩了 → 我要请求什么。多数时候走完第三步，那句最想说的话就不必说了。

## 08 适合谁读

**适合**

- 跨部门协作、带团队、做客户支持或销售的人——你的大部分工作成本都花在"解释"上。
- 亲密关系、亲子关系反复卡在同一个点上的人——重复的争吵通常意味着双方都在争"谁对"，没人说"我要什么"。
- 习惯说"不得不"的人。这本书对这类人的价值最大。
- 写文档、写评审意见、做绩效反馈的人——观察与评论的区分直接决定文字是否可执行。

**不适合，或者需要提前知道**

- **想学"高情商话术"去操控别人的人。** 这套方法的前提是你真的在乎对方的需要。抽掉这个前提，四要素只是更高级的施压，而且更容易被识破。
- **权力严重不对等、对方根本无意沟通的场景。** 书里第十一章给了另一条路：保护性强制力。不要用"我们在沟通"来掩盖伤害正在发生。
- **把它当心理治疗。** 它是一套沟通方法，不是创伤处理方案。涉及家暴、持续抑郁、成瘾，应寻求专业帮助。
- **期待它立刻见效的人。** 四要素说起来四句话，做起来是改归因习惯，通常以年计。
