# 绝叫 · 精读笔记

> 怀才者的自怜是天鹅的挽歌，平庸者的崩坏是野兽的绝叫。

## 01 书籍信息

| 项 | 内容 |
|---|---|
| 作者 | 叶真中显（1976— ），日本社会派推理作家 |
| 领域 | 推理小说 · 社会派 / 日本文学 |
| 首版 | 2015 年光文社；中文版 2020 年北京联合出版公司 |
| 体量 | 约 31.8 万字，三线并行，30 章交替 |
| 荣誉 | 第 16 届书店大奖第 2 名；豆瓣 2020 年度推理·悬疑 Top1 |
| 核心命题 | 一个人如何被做成"可以消失的人" |

《绝叫》不是一本"谁是凶手"的推理。它一上来就把结局摊开：东京国分寺的廉价公寓里，一具女尸被屋里十一只猫啃食殆尽，猫也全饿死了。警方初步判定为"孤独死"。真正要解的问题只有一个——这个叫铃木阳子的女人，是怎么走到这一步的。

## 02 一句话总览

这本书最锋利的判断：阳子不是"死于孤独"，而是被人、被制度、被四十年，一步一步**折算**成了一个可以消失的人。

## 03 核心框架：被折算的一生 vs 学会折算的手

这本书真正的推理引擎，不是凶器，不是不在场证明，而是一门**算术**——把人换算成数字的算术。前半生，阳子是**被折算的对象**；后半生，她成了**操作折算的人**。而她用的算法，一个字没改。

**被折算的一生（定价权在别人手里）**

- 出生即被称斤：母亲偏爱弟弟，弟弟的名字反复推敲，她的名字是随手取的最普遍女婴名
- 被折算成 KPI：保险推销员自掏腰包买保单冲指标（自爆营业），也用身体换单
- 被折算成肉身：负债后进入风俗业，网页上挂出的三围、年龄、经历全是可以掺水的参数
- 被折算成统计：死后被归为"孤独死"——社会把它读作她个人的选择，责任自动清零

**学会折算的手（用同一套算法反过来定价别人）**

- 保险公司教会她：一条命 = 保额 × 受益人，理赔流程她比谁都熟
- 神代一伙教会她：流浪者 = 生活补助 + 保险金的载体，"救助"只是壳
- 她学会后反手使用：假结婚 → 高额保单 → "意外"死亡 → 领取保险金
- 最后一层：当身份本身只是一串可以篡改的代码，人就彻底成了可被替换的数字

**推理引擎**：一个人被反复折算成数字，迟早会掌握这门算术——而这本书里，这门算术的名字叫"保险"。

三重叙事对应三种"读数"：**第二人称"你"**是被推着走的当事人；**第三人称"她"**是警察与社会眼中一具待分类的尸体；**第一人称供述碎片**是把人命当账目的人自己的说法。三条线在终章撞到一起。

## 04 关键概念

1. **名字** —— 被认真对待的人有名字，其他人只有一个称呼。她半生追逐"被需要"，源头在此。
2. **自爆营业** —— 推销员自掏腰包买保单充业绩；公司把经营风险转嫁给最没有议价能力的员工。
3. **就业冰河期与非正规雇佣** —— 泡沫崩坏后的派遣用工挤压；努力仍有效，但天花板已压下来。
4. **孤独死** —— 被发现以月计的独居者之死；一旦被归因为"选择"，责任自动清零。
5. **Kind Net 与"围栏族"** —— 借救助流浪者之名，行侵吞补助与骗保之实。
6. **保险金杀人** —— 假结婚、高额保单、"意外"死亡、受益人领取；成立靠的是流程而非暴力。
7. **金鱼** —— 五岁庙会所得，五天即死，尸身被野猫叼走；与终局被十一只猫啃食的尸体呼应，也是弟弟鬼魂的形态。
8. **第二人称叙事** —— "你"究竟指向谁，是全书最后一个反转；作案手法与叙事手法焊在一起。

## 05 全书脉络

```
【第二人称线 · 阳子】1973—2013，四十年
出生（母亲偏爱弟弟）→ 弟弟小纯被霸凌自杀 → 父亲负债失踪
→ 母亲投奔舅舅，把阳子像垃圾一样丢下
→ 东京：客服 → 保险推销员（自爆营业 · 与上司芳贺）
→ 被辞退、负债 → 风俗业（肉身被明码标价）
→ 遇神代武 → 加入 Kind Net 一伙
→ 假结婚 + 高额保单 + "意外"死亡 = 保险金（反复作案）
→ 分赃分歧（近三亿日元）→ 神代身中二十余刀身亡
→ 终章：第二人称"你"究竟是谁，反转揭晓

【第三人称线 · 刑警奥贯绫乃】
公寓女尸（被十一只猫啃食）──┐
                            ├→ 两案并线 → 真相：不是孤独死
NPO 代表神代武被刺杀 ────────┘

【供述碎片 · 相关人的第一人称】穿插于绫乃章节末尾
```

1973 到 2013，正好四十年。泡沫崩坏、就业冰河期、非正规雇佣扩张、贫困固化——不给时代一句台词，只让它落在一个人身上。

## 07 对工作与决策的行动启发

1. **指标会自己长出行为。** 自爆营业不是员工坏，是激励设计把风险转嫁给了最没有议价能力的人。定 KPI 先问：这个数字被压垮时，成本落在谁身上。
2. **流程是中性的，但流程与人结合会定向。** 保险金杀人靠"文件齐、条款对"。凡"合规即自动通过"的环节，都要补一眼对人的核验。
3. **警惕"这是他自己的选择"。** 把结构性问题归因为个人选择，是责任清零最快的方式。看到掉队的人，先数推力，再谈意志。
4. **善意通道必须配核验。** 救助 NPO 变成收割工具，不是因为招牌是假的，而是因为没人查。
5. **身份是一串代码，别让系统只认代码。** 凡把人压成单一 ID 的系统，都要留一条"活人复核"的后路。

## 08 适合谁读

- 喜欢社会派推理、想看"动机比手法更难解"的读者
- 关心经济周期如何落到具体个人身上的人
- 做管理、定指标、设计激励与流程的人（一份反面教材样本）
- 想理解孤独死、女性贫困、底层互助组织变质等日本社会议题的人
- 能接受全书几乎没有一个好人、读起来相当窒息的读者
