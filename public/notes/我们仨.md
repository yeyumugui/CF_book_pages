# 我们仨 · 精读笔记

> **一句话总览**：杨绛用一场"万里长梦"写两次死别——医院成了客栈，病床成了泊在水上的船，她沿着一条古驿道一次次去送；然后独自回到人间，用回忆把散掉的"我们仨"重新拼成一个不会散的家。

## 01 书籍信息

- **作者**：杨绛（1911—2016），作家、翻译家、戏剧家，钱锺书之妻，女儿钱瑗。
- **领域**：散文 / 回忆录
- **出版**：2003 年，生活·读书·新知三联书店；写作时杨绛 92 岁
- **核心命题**：家不是一处房子，是三个人在一起。当两个人先后被"送走"，剩下的那个人要如何安放一个已经散掉的家。

## 02 一句话总览

92 岁的杨绛写下这本书时，"我们仨"只剩她一个人。全书前半是一场"万里长梦"：钱锺书被一辆车接走，住进古驿道水边的船上，钱瑗住进另一家"客栈"，她在两地之间一次次奔波相送，直到"我们仨失散了"。后半是流水账式的回忆：牛津的探险、上海的乱世、干校的分离、三里河寓所的日常——把日子过具体，就是家的建造方式。

## 03 核心框架：一场散场，与一次重聚

**这本书真正的推理引擎**：家可以被现实拆散，但"我们"可以靠思念重造。杨绛不直接写悲恸，而是写**相送的过程**——离别被拉得越长，痛苦被摊得越薄，记忆却被压得越实。第二部整章使用梦的语法：医院叫客栈、病床叫船、死亡叫"失散"，拒绝直视的东西被翻译成一场可以一步步走完的长梦。

| 古驿道 · 散场（现实维度） | 「我们仨」· 不散（记忆维度） |
| --- | --- |
| 钱锺书被一辆车"接走"，住进古驿道边的船上 | 牛津的"探险"、家里的"打仗"、轮流做灶下婢 |
| 每天在客栈与船之间奔波探望，不能久留 | 三人各有分工、各有绰号，缺一个就不成"我们" |
| 阿圆也住进"客栈"，两处牵挂隔水相望 | 钱瑗走后、锺书走后：我一个人思念我们仨 |
| 人生是越走越窄的路，相聚全是临时的 | 思念是重建的技术：只要还在记，家就没有散 |
| 每一次探望都通向同一种结局：送别 | 写下这本书，本身就是把家重新拼起来的动作 |

## 04 关键概念

| 概念 | 要点 |
| --- | --- |
| 万里长梦 | 全书后半是一个被作者自己承认的"梦"：两年的生离死别被拉成古道、船、客栈；梦的语法让死亡可以被"送"，而不必被"看"。 |
| 古驿道 | 钱锺书被车接走后住进古驿道水边的船；古驿道是人间最后一程的相送之路，能做的只是一趟一趟地去。 |
| 客栈与船 | 医院在梦里叫客栈，病床是泊在水上的船：不能久留、只能探望——给"陪护与告别"重新命名，把最重的处境放进最轻的词里。 |
| 探险 | 牛津时期钱锺书把散步叫"探险"，专挑没走过的路走；晚年杨绛独自重走仍叫探险——把日子过成仪式，是家最结实的地基。 |
| 打仗 | 钱家黑话：远行、出国、下放都叫"打仗"；锺书"拙手笨脚"，回来就闯祸由妻女善后——彼此需要、彼此收拾，才是家的骨架。 |
| 打扫现场 | 阿圆走后，杨绛说自己得留在人世间"打扫现场，尽我应尽的责任"——留下来的人不是在等，是有事做的人。 |
| 三里河寓所 | "我们仨"最后的居所；人散之后杨绛只肯叫它"客栈"——房子还在，家已经跟着人走了。 |
| 彩云易散 | 全书以白居易句收束："世间好物不坚牢，彩云易散琉璃脆。"易碎性是底层判断，而写下来是对易碎性的回答。 |

  │        钱瑗（阿圆）1937 年生于牛津

  │        上海孤岛 · 相守相助 · "相聚不失散"

  │        探险 / 打仗 / 轮流"做灶下婢"

  │        两地书 · 学问是唯一的行李

## 06 金句

> "世间好物不坚牢，彩云易散琉璃脆。"
> —— 白居易《简简吟》原句，杨绛引作全书结语（第三部末）

> "我一个人思念我们仨。"
> —— 第三部题眼，全书最著名的一句话

> "家在哪里，我不知道。我还在寻觅归途。"
> —— 第二部结尾，梦醒之处

> "离别拉得长，是增加痛苦还是减少痛苦呢？我算不清。但是我陪他走得愈远，愈怕从此不见。"
> —— 基于第二部「古驿道」段落的提炼改写，非逐字原文

> "我得留在人世间，打扫现场，尽我应尽的责任。"
> —— 基于第二部「我们仨失散了」段落的提炼改写，非逐字原文

## 07 对工作与决策的行动启发

1. **把家记录下来**——共同生活的具体记录（照片、账本、闲话）是日后重建的建筑材料，拆不走。
2. **给日常起名字**——"探险""打仗"是钱家的内部语言；一个团队/家庭有自己的词汇表，就比制度更结实。
3. **把告别拉长**——能慢慢说的告别比突然的告别更容易承受；重要关系不要攒到"最后一次"才表达。
4. **留下的人要有事做**——"打扫现场"是把哀伤翻译成责任；失去之后最先恢复的是"有事可做"，不是"想开了"。
5. **知道会碎，照样去爱**——底色判断是"彩云易散"，但正因易碎，每一顿饭、每一次散步才值得记下来。

## 08 适合谁读

- 经历过亲人离别、正在"打扫现场"的人
- 以为来日方长、把陪伴无限推迟的人
- 中年家庭：正在体会"被需要"与"送别"并行的人
- 喜欢克制、不煽情、以轻写重的文字的人
- 想读杨绛——从这本开始比从译著更近
